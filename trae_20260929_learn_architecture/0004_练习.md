失败模式  → 下游执行了吗？ → 该不该重试？
连不上   → 未执行         → 可以重试
连上了不回应   → 执行了   → 不应该重试
回应了是错的   → 过载、限流，未执行   → 可以重试
回应了是错的   → 参数验证错误，执行了   → 不应该重试
回应了但很慢   → 执行了   → 不应该重试
部分成功       → 执行了   → 不应该重试
