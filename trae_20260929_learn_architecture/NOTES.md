# NOTES

## 用户偏好
- 回复与文档一律用**中文**。
- 教学形式：概念 + 练习结合。每节课一个紧凑知识点，配一个必须动手输出的设计练习，并给出反馈。
- 练习素材：**仿真需求**（无真实项目）。必要时后期可切换到真实系统。
- 主力技术栈：**Go + Java**，两者都要覆盖。
- 不确定就直接停下来问，不要瞎猜。

## 工作约定
- 若课程中出现 Go 代码片段，格式化使用 `D:\tools\gofmt\gofmt.exe`，不使用系统 `gofmt`。
- 教材必须挂**一手权威来源**链接（官方文档、原论文、SEI/AWS/Azure/Fowler 等），不靠模型记忆下结论。

## 学习节奏偏好（2026-09-29 观察）
- 用户倾向**直接推进课程**：第 2 课后被要求重写 ADR 时，他选择「跳过重写，直接上第 3 课」。
- 应对方式：需要纠正的误区**嵌入下一课开头的「补正」短节**（5 分钟、含正确示例），而不要把课程卡在「先重做练习」上。
- 练习设计保持「一课一个新动作」，避免在同一个动作上反复要求返工。
